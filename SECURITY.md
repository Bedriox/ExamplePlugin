# Security policy

Bedriox ExamplePlugin is pre-alpha and has no supported production release.

Do not report suspected vulnerabilities in public issues. Contact the Bedriox
team through [bedriox.com](https://bedriox.com/) until a dedicated private
GitHub security-reporting workflow is enabled. Include the affected revision,
impact, reproduction steps, and any proposed mitigation. Do not include live
credentials, authentication chains, player identifiers, or unrelated personal
information.
